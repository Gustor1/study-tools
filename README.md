# Study tools

Showcase of the interactive revision tools I build for my engineering courses at UTBM: an in-browser SQL trainer, a Cisco IOS simulator and cabling lab, a 438-card networking quiz, a Java lab trainer and an English workshop.

**Live page:** https://gustor1.github.io/study-tools/

The tools themselves are built on course material that belongs to the teaching staff, so their sources are private. This repository only holds the showcase page and screenshots of my own exercises and interface.

Static HTML and CSS, no build step, no dependencies.
